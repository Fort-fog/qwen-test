Мини-мессенджер для Redmi

Цель: простой, быстрый мессенджер для Android.

Вход: имя пользователя.

Чаты: список собеседников.

Сообщения: отправка и получение текста.

История: сохранение переписки.

Дизайн: лёгкий интерфейс, удобный на экране Redmi.

Технологии: Kotlin + Android Studio, Firebase для сообщений и авторизации.

Первый этап: сделать рабочий чат между двумя телефонами.

Без звонков, каналов, ботов и лишних функций.
